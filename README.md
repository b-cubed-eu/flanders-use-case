This project is part of the **B-Cubed initiative**, which develops and applies biodiversity indicators using regional datasets. In this case study, the B-Cubed workflows are tested for **Flanders**, a region in Europe with abundant species occurrence data.  

The focus is on several types of indicators:  
- **General biodiversity indicators** (e.g., cumulative species richness, relative species richness)  
- **Phylogenetic indicators** (via `pdindicatoR`)  
- **Invasive Alien Species indicators** (via `impIndicator`) extended with additional reporting indicators  
- Extra attention is given to comparisons between **Natura 2000 vs. non-Natura 2000 habitats**, uncertainty estimation, and survey effort.

## 🎯 Dashboard Objective

The associated dashboard visualizes the selected indicators and serves as inspiration for other dashboards (e.g., the Alien Species Portal and the Flemish Biodiversity Portal). The dashboard provides:  
- Visualizations of general, phylogenetic, and invasive species indicators  
- Comparison between habitats  
- Open access to code and results for reuse and interoperability
